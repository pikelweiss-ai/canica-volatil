# Pre-Alpha v1.0.0

Primera versio descarregable de Canica Volatil. Joc offline de combat i masmorres amb caniques.

## Paquets
- Windows x86_64: ZIP amb executable i totes les dependencies. Extraure i obrir CanicaVolatil.exe.
- Linux Mint / Linux x86_64: TAR.GZ amb executable natiu i Jugar.sh. Extraure i executar el llancador; alternativa: bash Jugar.sh.
- SHA256SUMS.txt: sumes de comprovacio dels dos paquets.

## Contingut
Masmorres procedurals, huit temes, enemics i tres bosses; armes a distancia i cos a cos, inventari, cofres i cures.
Personalitzacio amb 22 skins, 13 opcions de barret i 12 esteles, incloent opcions sense accessori.
Radar transparent, controls reassignables, volums independents i menu de pausa amb tres barres.

## Verificacio i limits
Les dues compilacions han acabat amb zero errors. Windows s'ha executat fora de l'Editor i ha passat menu i entrada a masmorra.
Linux s'ha compilat nativament pero encara no s'ha executat en una maquina Linux Mint. No es dona per provada eixa compatibilitat.
No hi ha multijugador. Esta es una pre-alpha: encara queden proves de partida completa, equilibri i casos especials.
El runtime Windows inclou el pegat oficial Unity Application Patcher 1.3.3 per CVE-2025-59489.
El runtime Linux es el de Unity 6000.0.53f1; no se li ha aplicat el pegat de Windows.

El repositori i les descarregues son privats i requereixen acces autoritzat.
